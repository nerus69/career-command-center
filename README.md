# Career Command Center

A deliberately small, offline-first job-search dashboard. Track roles, interviews, follow-up dates, and one focused weekly goal.

## Run it

Open `index.html` in any modern browser. No installation, account, or network connection is needed.

## What it includes

- A compact opportunity pipeline with saved, applied, and interview stages
- Live counts for active roles, upcoming follow-ups, and interviews
- Persistent browser storage for your roles and weekly goal
- A responsive interface designed to feel focused rather than busy

## Privacy

All data stays in the browser via `localStorage`; nothing is sent anywhere.
